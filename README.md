# 포모도로 + 할일 트래커

집중 시간과 할 일을 함께 관리하는 싱글 페이지 웹 앱입니다. 별도 설치나 빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 실행 방법

`index.html` 파일을 웹 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

- **포모도로 타이머**: 집중(25분) / 짧은 휴식(5분) / 긴 휴식(15분) 모드 전환
- **할 일 목록**: 할 일 추가, 완료 처리, 삭제
- **집중 대상 지정**: 할 일을 클릭해 집중 대상으로 지정하면, 완료된 뽀모도로가 해당 항목에 기록됩니다
- **통계**: 오늘 완료한 뽀모도로 수, 이번 주 완료 수, 연속 달성일(스트릭)
- **로컬 저장**: 브라우저의 `localStorage`에 진행 상황이 저장되어 새로고침해도 유지됩니다

## 기술 스택

순수 HTML / CSS / JavaScript (프레임워크나 외부 라이브러리 없음)
